# 3D 打印机喷头 OK/NG 检测实验记录

## 1. 项目目标

本项目面向 3D 打印机喷头状态检测，基于 YOLOv5 训练 OK/NG 两类目标检测模型。系统用于打印前或关键节点检测喷头状态，发现高危污染、裹头、无挤出、遮挡等异常后及时报警或停机。

### 1.1 业务目标

- 检测对象：3D 打印机喷头区域。
- 检测类别：
  - `0: NG`：喷头裹头、无挤出、重污染、轻微污染、遮挡等异常状态。
  - `1: OK`：喷头清洁、正常挤出等正常状态。
- 使用场景：
  - 打印开始前检测 1 次。
  - 必要时可取 5 帧投票，3 帧及以上异常则报警。
  - 中途检测需要谨慎，因为频繁检测可能影响打印质量。

### 1.2 验收指标

| 指标 | 目标值 | 说明 |
| --- | ---: | --- |
| 准确率 | >= 90% | 整体状态判断正确率 |
| 精确率 P | >= 98% | 客户更关注高 P，减少误报警 |
| 召回率 R | >= 80% | NG 漏检仍需重点监控 |
| 推理耗时 | <= 300 ms | 从拍照到输出状态 |
| 业务阈值 | conf 0.7 左右重点观察 | 高 P 场景优先分析高阈值表现 |

## 2. 老师实验过程摘要

### 2.1 数据分析主线

老师实验过程强调先理解数据，再做训练：

1. 分析类别分布，判断是否存在类别不平衡。
2. 分析目标框大小，判断是否存在小目标、大目标和异常面积目标。
3. 分析目标框宽高比，判断 anchor 或检测头是否适配。
4. 分析图像质量，重点关注曝光过度、目标不明显、遮挡等情况。
5. 人工检查标注质量，记录错标、漏标、框偏移、框过大或过小的问题。
6. 做去重，优先处理完全重复样本，再检查视觉近重复样本。

### 2.2 已知数据问题

- 类别不平衡：NG、OK 以及各原始子类数量差异明显。
- 图像过亮：存在曝光过度，可能导致目标边界不清晰。
- 标注不规范：部分 GT 框与预测框 IoU 低，可能是标注框质量问题。
- 目标形状跨度大：目标宽高比曾观察到约 `1.65 ~ 5.20`，平均约 `3.95`。
- 目标尺寸分布复杂：大中小目标都存在，大目标和小目标都可能造成漏检。
- 重复样本：老师流程中曾发现训练集和验证集存在完全重复样本。

### 2.3 训练与调参主线

老师实验过程中的关键训练思路：

1. 先建立基线，关闭或控制增强，观察 YOLOv5 与其他模型的基本能力。
2. 对类别不平衡场景使用 `image_weights`。
3. 对固定相机工业场景，谨慎使用强几何变换，尤其避免不合理透视增强。
4. 初始学习率可从 `lr0=0.0001` 开始。
5. 高 P 阶段可降低或关闭 `mixup`。
6. 当基础指标较高后，再尝试 `fl_gamma=1.5` 等 Focal Loss 方案。
7. 对 IoU 误判和框质量问题，可考虑 SIOU 或标签修正。
8. 对低置信度样本，可做锐化、亮度抑制、过曝模拟等困难样本增强。
9. 如果训练轮数不足，mAP50-95 可能仍有提升空间，可拉长训练观察。

### 2.4 错误分析主线

每轮训练后需要重点看：

- 低置信度样本。
- 假阴性，即 NG 漏检。
- 假阳性，即 OK 被误报为 NG。
- 预测框与 GT 框 IoU 低的样本。
- 标签错误或框不规范样本。
- 过曝、遮挡、目标不可见、目标过大或过小样本。

老师实验中提到，部分预测框可能比 GT 框更合理，这类样本应进入人工复核，不能只看指标下结论。

## 7. 训练策略记录

### 7.1 基线训练

目标：先得到可复现 baseline，不急着堆复杂增强。

建议记录：

- 是否使用预训练权重。
- 是否开启 image_weights。
- 是否开启 multi_scale。
- 是否关闭 mixup。
- 是否使用默认 CIOU。

### 7.2 增强实验

可选增强方向：

- 亮度抑制。
- 对比度增强。
- 锐化增强。
- 缩放增强，模拟小目标和大目标。
- 复制粘贴增强，模拟过曝或全光源情况。

每次增强都需要记录：

- 增强来源样本。
- 增强数量。
- 增强后人工抽检结论。
- 是否引入错误标签或不自然样本。

### 7.3 Loss 与结构实验

可选方向：

- Focal Loss：基础 P/R 较高后再尝试。
- SIOU：当预测框和 GT 框 IoU 判断不稳定时尝试。
- 注意力机制：CAM 显示某层特征不足时再考虑。
- 冻结部分层：需谨慎，老师实验中只训练第 19 层效果不理想。
