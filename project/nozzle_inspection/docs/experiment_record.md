# 3D 打印机喷头 OK/NG 检测实验记录

## 1. 项目目标

本项目面向 3D 打印机喷头状态检测，基于 YOLOv5 训练 OK/NG 两类目标检测模型。系统用于打印前或关键节点检测喷头状态，发现高危污染、裹头、无挤出、遮挡等异常后及时报警或停机。

### 1.1 业务目标

- 检测对象：3D 打印机喷头区域。
- 检测类别：
  - `0: NG`：喷头裹头、无挤出、重污染、轻微污染、遮挡等异常状态。
  - `1: OK`：喷头清洁、正常挤出等正常状态。
- 使用场景：
  - 打印开始前检测 1 次。
  - 必要时可取 5 帧投票，3 帧及以上异常则报警。
  - 中途检测需要谨慎，因为频繁检测可能影响打印质量。

### 1.2 验收指标

| 指标 | 目标值 | 说明 |
| --- | ---: | --- |
| 准确率 | >= 90% | 整体状态判断正确率 |
| 精确率 P | >= 98% | 客户更关注高 P，减少误报警 |
| 召回率 R | >= 80% | NG 漏检仍需重点监控 |
| 推理耗时 | <= 300 ms | 从拍照到输出状态 |
| 业务阈值 | conf 0.7 左右重点观察 | 高 P 场景优先分析高阈值表现 |

## 2. 老师实验过程摘要

### 2.1 数据分析主线

老师实验过程强调先理解数据，再做训练：

1. 分析类别分布，判断是否存在类别不平衡。
2. 分析目标框大小，判断是否存在小目标、大目标和异常面积目标。
3. 分析目标框宽高比，判断 anchor 或检测头是否适配。
4. 分析图像质量，重点关注曝光过度、目标不明显、遮挡等情况。
5. 人工检查标注质量，记录错标、漏标、框偏移、框过大或过小的问题。
6. 做去重，优先处理完全重复样本，再检查视觉近重复样本。

### 2.2 已知数据问题

- 类别不平衡：NG、OK 以及各原始子类数量差异明显。
- 图像过亮：存在曝光过度，可能导致目标边界不清晰。
- 标注不规范：部分 GT 框与预测框 IoU 低，可能是标注框质量问题。
- 目标形状跨度大：目标宽高比曾观察到约 `1.65 ~ 5.20`，平均约 `3.95`。
- 目标尺寸分布复杂：大中小目标都存在，大目标和小目标都可能造成漏检。
- 重复样本：老师流程中曾发现训练集和验证集存在完全重复样本。

### 2.3 训练与调参主线

老师实验过程中的关键训练思路：

1. 先建立基线，关闭或控制增强，观察 YOLOv5 与其他模型的基本能力。
2. 对类别不平衡场景使用 `image_weights`。
3. 对固定相机工业场景，谨慎使用强几何变换，尤其避免不合理透视增强。
4. 初始学习率可从 `lr0=0.0001` 开始。
5. 高 P 阶段可降低或关闭 `mixup`。
6. 当基础指标较高后，再尝试 `fl_gamma=1.5` 等 Focal Loss 方案。
7. 对 IoU 误判和框质量问题，可考虑 SIOU 或标签修正。
8. 对低置信度样本，可做锐化、亮度抑制、过曝模拟等困难样本增强。
9. 如果训练轮数不足，mAP50-95 可能仍有提升空间，可拉长训练观察。

### 2.4 错误分析主线

每轮训练后需要重点看：

- 低置信度样本。
- 假阴性，即 NG 漏检。
- 假阳性，即 OK 被误报为 NG。
- 预测框与 GT 框 IoU 低的样本。
- 标签错误或框不规范样本。
- 过曝、遮挡、目标不可见、目标过大或过小样本。

老师实验中提到，部分预测框可能比 GT 框更合理，这类样本应进入人工复核，不能只看指标下结论。

### 3.5 跨集合精确重复清理

进一步观察发现，原始数据来自视频抽帧，连续帧之间可能高度相似。如果相邻帧或完全重复帧被分散到 `train`、`val`、`test` 中，验证集和测试集就可能包含训练阶段几乎见过的画面，导致评估指标虚高。

后续更合理的数据划分思路是：

- 先将原始 `train`、`val`、`test` 统一纳入分析，做全局重复和相似样本检查。
- 将连续帧或高度相似样本聚成同一组。
- 重新划分时以“视频片段/相似簇”为单位分配到 `train`、`val`、`test`，避免同一组高度相似样本跨集合出现。
- 在此基础上，再尽量保持 OK/NG 类别、曝光、遮挡、污染程度等难易样本分布均衡。

本次先在第 3.4 节输出的 `out` 数据集基础上，补做跨集合精确 hash 重复检测。该步骤只处理完全重复图片，不处理跨集合视觉相似样本。

检测与移除规则：

- `val` 对 `train` 做精确 hash 重复检测；若重复，移除较大的 `train` 集合中的副本。
- `test` 对 `train` 做精确 hash 重复检测；若重复，移除较大的 `train` 集合中的副本。
- `test` 对 `val` 做精确 hash 重复检测；若重复，移除较大的 `val` 集合中的副本。
- 原始 `dataset_2` 和上一版 `out` 均不删除、不移动，新结果输出到 `out_cross_hash_clean`。

### 5.0 当前数据质量结论

当前推荐训练数据版本为 `out_cross_hash_clean`，共 2380 张有效图片和 2380 个标签文件。该版本已经完成：

- 各集合内部精确重复与视觉相似样本清理。
- `val/train`、`test/train`、`test/val` 跨集合精确 hash 重复清理。
- 图片与标签一一对应验证。

综合分析后，当前数据集的主要特点是：

- OK/NG 总体接近均衡，但 `train` 中 NG 占比略高，`val`、`test` 中 OK 占比略高。
- 喷头目标整体为横向长条形，宽高比范围约 `1.53 ~ 5.45`，默认 anchor 可能需要重点观察。
- OK 类目标平均面积明显小于 NG 类，OK 样本更容易受到小目标、反光和纹理干扰。
- `val`、`test` 小目标占比较高，后续如果验证集召回率偏低，不能只判断模型能力不足，还要结合目标尺度分布分析。
- 过曝、强反光、低清晰度是当前图像质量风险，容易导致目标边界不清、框定位不稳或低置信度。

## 6. 正式训练流程

本项目接下来进入训练阶段。训练顺序应保持克制：先跑可复现 baseline，确认数据、标签、指标和错误样本导出流程都通，再做增强、loss 或结构实验。

### 6.1 训练阶段安排

| 阶段 | 实验目标 | 数据版本 | 核心原则 | 进入下一阶段条件 |
| --- | --- | --- | --- | --- |
| Baseline | 建立第一版可复现基准 | `out_cross_hash_clean` | 尽量少改参数，先看真实能力 | 训练、验证、错误样本导出流程全部跑通 |
| 数据复查 | 根据误检/漏检复查标签和困难样本 | `out_cross_hash_clean` | 优先修数据问题，不急着调模型 | 明确错误是否集中在过曝、小目标、标注框问题 |
